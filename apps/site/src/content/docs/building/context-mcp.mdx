# Context & MCP

Context is the library your Agents are equipped from. It comes in two forms:
**MCP connections** — Model Context Protocol servers, at workspace or personal
scope — and authored **skills** with drag-and-drop attachments. Equipping an
Agent packages both straight into its compiled artifact, so a published Agent
carries its tools and knowledge with it.

Adding a connection is a three-lane flow: a curated connector catalog with
one-click install, community search over a mirrored index of the official MCP
registry (every install is re-verified against the live registry), and a custom
server URL for anything else. Any credentials a connection needs are stored
write-once and encrypted; the API only ever reports whether a connection has
credentials, never their values.
